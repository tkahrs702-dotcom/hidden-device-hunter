# 2026-10-05 build manual: schematics and pin-to-pin wiring diagrams
Asked by Taelor in the Claude app Project (thread "Build manual with schematics"): a very thorough instruction manual with electrical
schematics and pin-to-pin wiring diagrams. Done in a cloud session; no hardware involved.

- Added 8 SVG diagrams in `docs/manual/diagrams/` (system overview, level shifter, wiring + schematic for each of Phases 1-3), generated by
  `tools/diagrams/make_diagrams.py` (plain Python, no dependencies). `tools/diagrams/render.sh` makes PNG previews with Chromium headless_shell.
- Rewrote `01` and `02` as step-by-step guides: wire IDs, jumper types, soldering, continuity and voltage checks before/after power,
  arduino-cli flash commands (`arduino:renesas_uno:unor4wifi`, `esp32:esp32:XIAO_ESP32S3`), expected boot output, commands, what the
  beeps/matrix mean, aiming, troubleshooting. `03` got diagrams, wire IDs and meter checks; `05` a diagram index, colour legend, every wire by ID,
  the XIAO -> R4 line protocol.
- Pin numbers checked against the sketches: buzzer D8, R4 Serial1 D0/D1, XIAO LINK_TX D6 (GPIO43) / LINK_RX D7 (GPIO44), BOOT GPIO0.
- Found while drawing: the R4 has one 5V pin and socket headers, so Phase 2 uses the breadboard's bottom rail for 5 V and needs M-M/M-F jumpers,
  not only F-F. Shopping list updated.
- Phase 3 (no firmware yet): swapped the two GND pins (XIAO -> pin 5, BNO085 -> pin 10) to untangle the wiring. Electrically identical.
- Not verified on hardware: physical positions of the XIAO u.FL socket and P4 connectors in the drawings are approximate; pin order is exact.
