## Manual
Full manual in `docs/manual/` (written 2026-10-03; rebuilt 2026-10-05 into a step-by-step build guide). Each phase: parts, SVG wiring diagram + schematic
(`docs/manual/diagrams/`, generated by `tools/diagrams/make_diagrams.py`), wire list with IDs (W/P/S/A/T/I/O), assembly steps, meter checks before power,
flashing with arduino-cli, use, troubleshooting. Pin data checked against the Waveshare schematic and docs, Seeed, Arduino core source, Adafruit board files and the sketches.
2026-10-05 build decisions: half-size breadboard holds the Phase 1 buzzer and distributes Phase 2's 5 V (R4 has one 5V pin); jumper kit needs M-M, M-F and F-F
(R4 and breadboard are sockets); generic BSS138 shifter (LV1-4/HV1-4) mapped to Adafruit 757 (A/B) in 02 sec. 2.2; Phase 3 GND pins swapped
(XIAO GND -> P4 pin 5, BNO085 GND -> pin 10) so BNO085 uses only pins 2/4/6/10.
